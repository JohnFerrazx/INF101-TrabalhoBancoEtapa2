# TrabalhoBancoEtapa2
INF101 Trabalho – Implementação de um Sistema de Registro e Gestão de Contas Bancárias - Aluno: João Pedro Ferraz Barreto  Matrícula: 29059

Este projeto foi desenvolvido como parte da Etapa 2 do trabalho da disciplina INF01, com o objetivo de ampliar o sistema de registro e gestão de contas bancárias desenvolvido na etapa anterior. Nesta etapa, o sistema passou a permitir o cadastro e gerenciamento de múltiplas contas bancárias, utilizando arrays para armazenar os dados dos clientes, números das contas, CPFs, tipos de conta e saldos. Também foi implementado um histórico de movimentações, permitindo registrar depósitos, saques e transferências entre contas. O sistema possui um menu interativo que permite cadastrar contas, listar as contas cadastradas, consultar uma conta específica, realizar depósitos, saques e transferências, além de consultar o extrato de movimentações de cada conta. Também foram implementadas validações para evitar cadastros duplicados, garantir valores positivos nas operações, verificar a existência das contas envolvidas e impedir saques e transferências com saldo insuficiente. Durante o desenvolvimento, foram utilizados conceitos da linguagem C++, como arrays, variáveis dos tipos int, string, double e bool, estruturas condicionais if/else, estrutura de repetição do while, estrutura switch e comandos de entrada e saída cin e cout. Esta segunda etapa representa a evolução do sistema, permitindo gerenciar várias contas e acompanhar suas movimentações, mantendo os dados armazenados em memória durante a execução do programa.
